# OpenDVA 工业化交付差距审计

审计时间：2026-06-10

## 结论

当前工程还不是完整可交付的工业桌面软件，但已经从纯 L1/headless 算法参考实现推进到 Desktop MVP 基线：CLI golden model 可以运行 Monte Carlo 并生成 HTML/CSV/Excel-XML 报告及 HST/HLM 分析文件，Qt6/Qt3D GUI 可以构建，具备主窗、Model Navigator、属性面板、文件流、分析窗口和基础 Qt3D 点/特征/测量线视图。真实 CAD/OCCT 几何、完整 MTM 对话框、产品级 Color Contour 云图和大量 3DCS 风格命令仍未交付。

现有代码最有价值的部分是接口、领域模型、部分 Move/Tolerance/Measure/Simulation/Report 引擎和测试基础。下一步应优先把它收敛成一个“可打开/编辑/保存/分析/报告”的最小可交付桌面版，而不是继续只扩 headless 算法清单。

## 审计范围

- 需求来源：`doc/需求文档.md`
- 开发计划来源：`doc/开发计划-多智能体协同.md`
- 当前实现来源：`src/`
- 运行证据：`build/app/cli/opendva.exe --runs 1000 --seed 12345 --out build/goal-smoke-report.html`

## 与技术约束的偏差

| 约束 | 当前状态 | 处理建议 |
|---|---|---|
| Qt6 | UI 使用 Qt6 Widgets，`OPENDVA_BUILD_UI` 默认 ON，当前验证会构建 `opendva_gui` | 保持 UI 作为产品构建目标之一 |
| Qt3D | 已引入 Qt3DCore/Qt3DRender/Qt3DInput/Qt3DExtras，`ModelViewport` 可显示点、特征 glyph 和测量线，并可接收 point deviation 数据映射点云颜色和显示交互式 Legend 范围控制；Contributor 结果已可映射到受控点 deviation；纯 C++ 层已有 Color Contour point-cloud、legend、viewport marker 和 contributor-to-point 数据；HTML 报告层可接收视图图片资产；UI HTML 导出可捕获并嵌入当前 Qt3D 视图截图 | 下一步补动画、截图质量控制和报告模板 |

## 建议的第一轮可交付范围

目标不是复刻全部 3DCS，而是交付一个可演示、可保存、可分析的 OpenDVA Desktop MVP。

必须完成：

1. UI 默认可构建：`OPENDVA_BUILD_UI=ON` 能找到 Qt6 Widgets + Qt3D 并生成 `opendva_gui`。
2. MainWindow 工业化骨架：菜单、工具栏、状态栏、停靠式 Model Navigator、属性/结果区域、Qt3D Graphic Window。
3. 文件工作流：New/Open/Save/Save As 接入 `ModelSerializer`，最近文件和脏状态提示。
4. Model Navigator：展示 Part/Point/Feature/Tolerance/Move/Measure/GD&T；支持重命名、启用/禁用、删除、Move 拖放排序。
5. 最小 MTM 编辑：可创建/编辑 Linear Tolerance、Point-Point Measure、Transform/SixPlane/TwoPoint/ThreePoint Move 的基础参数。
6. Simulation Window：运行 Monte Carlo，显示统计表、直方图、样本摘要，并能导出 HTML/CSV/Excel-XML/HST/HLM 报告/分析文件。
7. Qt3D 视图：显示点、特征简化几何、名义/当前位置，支持 Color Contour 数据映射、视角旋转/缩放/平移。
8. 验证门禁：CLI golden model 继续通过；新增 UI 构建验证；至少一个保存-打开-运行-导出报告的桌面端 smoke。

明确不做：

- AAO/FEA/Mechanical/CAD 深度集成。
- 全 3DCS 菜单图标和全部对话框。
- OCCT 完整替换，除非 Qt3D MVP 完成后仍有时间。

## 建议实施顺序

1. 先补 UI 壳与文件流：把当前 golden model demo 变成真实文档式应用。
2. 再补 Model Navigator 和最小 MTM 编辑：让用户能创建/修改而不是只能看内置模型。
3. 再补 Simulation Window 与报告导出：形成端到端业务闭环。
4. 再补 Qt3D Color Contour 动画、截图质量控制和报告模板：在现有 Qt3D Graphic Window 基线上满足需求第 8 章。
5. 最后补剩余 Move/Measure TODO 或 OCCT，根据验收反馈排序。

## 验收定义

第一轮工业化交付完成时，必须能在桌面 UI 中完成以下流程：

1. 新建模型。
2. 添加或编辑至少两个点、一个公差、一个测量。
3. 保存为 OpenDVA XML。
4. 关闭后重新打开文件，数据一致。
5. 运行 Monte Carlo。
6. 在 Simulation Window 看到统计表和图表。
7. 在 Qt3D Graphic Window 看到模型/点/偏差或云图。
8. 导出 HTML 报告。
9. 通过命令行验证和 UI 构建验证。
