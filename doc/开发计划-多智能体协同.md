# 3DCS 复刻——多智能体协同开发计划（核心全功能版）

> 依据：[README.md](README.md)（3DCS Variation Analyst 完整功能分析）。
> 范围：核心全功能版——21 种 Move、19 种 GD&T、全部 Measure、Monte Carlo / GeoFactor / Contributor 三引擎、
> Color Contour 可视化、报告输出。**暂不含** AAO 优化器、FEA 柔性、Mechanical 机构、5 个 CAD 平台深度集成（留接口）。
> 技术栈：**C++17 计算内核 + OpenCASCADE(OCCT) 几何 + Qt6 桌面 UI**，插件用 C ABI（对齐原 3DCS User DLL）。
> 协同模式：**按模块垂直划分**——每个智能体拥有一个模块，靠接口契约（IDL/头文件）协作。

## 1. 总体架构与分层

复刻 README §0.2 的四层架构，落到 C++/Qt/OCCT 工程：

```
┌──────────────────────────────────────────────────────────────────┐
│  L4 表现层 (Qt6 Widgets/QML)                                        │
│   Model Navigator(Logic Tree) │ MTM 编辑对话框 │ Simulation Window │
│   Graphic Window(OCCT Viewer) │ Report/Color Contour              │
└───────────────┬──────────────────────────────────────────────────┘
                │  Command/Signal (Qt 信号槽 + 命令模式)
┌───────────────▼──────────────────────────────────────────────────┐
│  L3 应用层 (Application Services, 纯 C++ 无 UI 依赖)                │
│   ModelDocument │ CommandStack(undo/redo) │ MtmEditorService      │
│   AnalysisOrchestrator │ ReportService │ ImportExportService      │
└───────────────┬──────────────────────────────────────────────────┘
                │  IDataModel 接口
┌───────────────▼──────────────────────────────────────────────────┐
│  L2 领域模型 (Domain Model, POD/值对象)                            │
│   AssemblyTree │ Part │ Point │ Feature │ GDT │ Tolerance │ Move  │
│   Measure │ Distribution │ ProcessCapabilityDB │ ModelVariant     │
└───────────────┬──────────────────────────────────────────────────┘
                │  ISolver / IGeometryKernel 接口
┌───────────────▼──────────────────────────────────────────────────┐
│  L1 计算内核 (Engine, 高性能 C++, 可独立测试/Headless)             │
│   GeometryKernel(OCCT 封装) │ MoveSolver(21) │ ToleranceSampler   │
│   MeasureEvaluator │ MonteCarloEngine │ GeoFactorEngine           │
│   ContributorEngine │ RNG(可复现) │ PluginHost(C ABI)             │
└────────────────────────────────────────────────────────────────────┘
```

**分层铁律**（智能体必须遵守）：
- L1 不依赖 L2 以上，**可脱离 UI 在命令行跑通完整仿真**（对齐 README §7.7 Batch Processor 思想，便于 CI 测试）。
- L4 不直接碰 L2/L1，只经 L3 应用服务。
- 模块间**只**通过 [§3 接口契约](#3-接口契约模块间唯一耦合点) 通信，禁止跨模块直接 include 实现头文件。

## 2. 模块划分与智能体分工

9 个垂直模块，每个由一个智能体负责（命名 `A0`~`A8`）。括号内为对应 README 章节。

| 智能体 | 模块 | 职责 | 对应 README | 关键产出 |
|---|---|---|---|---|
| **A0** | **架构 & 接口契约 + CI** | 定义所有跨模块接口、目录骨架、构建系统、CI 门禁、代码规范 | §0,§1 | `/interfaces/*.h`、CMake、CI、ADR |
| **A1** | **几何内核 GeometryKernel** | OCCT 封装：点/线/圆/平面/球/槽、Mesh 双层模型、LSQ 轴-平面/MaxCyl-MinCyl、6 种方向系统 | §3,§14.1 | `IGeometryKernel`、网格化、特征拟合 |
| **A2** | **领域模型 & Logic Tree** | AssemblyTree 有序树、Part/Point/Feature/GDT/Tole/Move/Measure 数据结构、序列化(WTX/XML)、ModelVariant、PCDB | §0.3,§3.1,§5.7 | `DomainModel`、WTX 读写、Tree Link |
| **A3** | **Move 求解器 MoveSolver** | 21 种 Move 的刚体 (R,t) 求解；Six-Plane 通用内核 + 退化版；孔销浮动、Bend、条件/迭代逻辑 | §4 | `IMoveSolver`、21 求解器 |
| **A4** | **公差抽样 ToleranceSampler** | GD&T 19 种→几何偏差映射、3DCS 公差、16+4 种分布抽样、RSS、Bonus/Datum Shift/Truncation | §5 | `IToleranceSampler`、分布库、GeomRule |

| **A6** | **仿真引擎 SimulationEngine** | Monte Carlo 主循环(可复现 RNG)、统计量、收敛、置信区间；GeoFactor 灵敏度矩阵；Contributor HLM；Batch | §7 | `ISimulationEngine`、统计量、Headless CLI |

> **A0 是协调者**：先行交付接口契约与骨架，其余 8 个智能体并行开发，全部对 A0 的接口编程。

**依赖拓扑（决定交付次序）**：
```
A0(接口) ──► 所有
A1(几何) ──► A3,A4,A5,A7
A2(模型) ──► A3,A4,A5,A6,A7,A8
A3,A4,A5 ──► A6(仿真编排三者)
A6 ──► A7(可视化读结果),A8(分析窗口)
A1,A2 ──► A7(渲染),A8(导航树)
```

## 3. 接口契约（模块间唯一耦合点）

由 A0 先行定义、版本化（`/interfaces/`），变更走 RFC。核心接口（C++ 抽象类，纯虚 + POD 值对象）：

### 3.1 几何内核接口（A1 实现，A3/A4/A5/A7 消费）
```cpp
// interfaces/IGeometryKernel.h
struct Vec3 { double x,y,z; };
struct Mat34 { double m[3][4]; };           // 刚体变换 [R|t]

class IGeometryKernel {
public:
  virtual ~IGeometryKernel() = default;
  // 几何实体（README §3.1）
  virtual FeatureId  createPlane(const std::vector<Vec3>& pts) = 0;
  virtual FeatureId  createCylinder(const std::vector<Vec3>& pts, double dia, HoleType) = 0;
  // 网格化双层模型（README §3.1.4）
  virtual MeshHandle meshFeature(FeatureId, const MeshParams&) = 0;  // MeshNodeNum/CadPtNum
  // 拟合（README §14.1）
  virtual Plane  fitLeastSquaresPlane(const std::vector<Vec3>&) = 0;
  virtual Axis   fitLeastSquaresAxis (const std::vector<Vec3>&, bool shiftOnly) = 0; // LSA/LSS
  virtual std::pair<double,double> maxMinCylinder(const std::vector<Vec3>&, const Axis&) = 0;
  // 方向系统 6 type（README §3.3）
  virtual Vec3 resolveDirection(const Direction&, const PointContext&) = 0; // 自动归一化 IJK
};
```

### 3.2 Move 求解器接口（A3 实现，A6 消费）
```cpp
// interfaces/IMoveSolver.h —— README §4 核心抽象「求 (R,t) 使 N 个标量约束满足」
struct MoveResult { Mat34 transform; bool ok; std::string log; }; // 失败回退+Run Log

class IMoveSolver {
public:
  virtual ~IMoveSolver() = default;
  virtual MoveType type() const = 0;
  // objectPts/targetPts/directions 由领域模型传入；rng 用于孔销浮动
  virtual MoveResult solve(const MoveInputs&, IRng& rng) = 0;
};
// 工厂：MoveType → IMoveSolver（Six-Plane 是通用内核，其它退化/有序版）
class MoveSolverFactory { public: static std::unique_ptr<IMoveSolver> create(MoveType); };
```

### 3.3 公差抽样接口（A4 实现，A6 消费）
```cpp
// interfaces/IToleranceSampler.h —— README §5
// 统一中间表示（README §5 复刻要点）
struct ToleranceIR {
  std::vector<RandSpec> rands;     // {distribution, range, offset, sigmaNum=(Max-Min)/6}
  Truncation trunc; double rangeScale;
  GeomRule geomRule;               // 沿向量平移/绕FLP旋转/节点法向偏移/截面径向/直径缩放
};
class IToleranceSampler {
public:
  virtual ~IToleranceSampler() = default;
  // 抽样并施加到特征几何（改 mesh/points，不改 CAD）
  virtual void applyDeviation(const ToleranceIR&, MeshHandle, IRng& rng) = 0;
};
class IDistribution { public: virtual double sample(double range,double offset,IRng&)=0; };
```

### 3.4 测量求值接口（A5 实现，A6 消费）
```cpp
// interfaces/IMeasureEvaluator.h —— README §6
class IMeasureEvaluator {
public:
  virtual ~IMeasureEvaluator() = default;
  // 每 build 返回一个标量（绑定装配节点，nominal/current 双轨）
  virtual double evaluate(const MeasureDef&, const BuildState&) = 0;
};
// DirectionMode 策略复用：TrueDistance/ProjVector/ProjPlane（README §6.1.3）
```

### 3.5 仿真引擎接口（A6 实现，A7/A8 消费）
```cpp
// interfaces/ISimulationEngine.h —— README §7
struct MeasureStats {            // README §7.3 全部统计量
  double mean, sigma, sixSigma, cp, cpk, pp, ppk;
  double lOutPct, hOutPct, totOutPct, dpmo, skewness, kurtosis;
  std::vector<double> histogram; // 直方图 bins
};
class ISimulationEngine {
public:
  virtual ~ISimulationEngine() = default;
  // Monte Carlo（README §7.2/7.3）—— 固定遍历顺序保 seed 可复现
  virtual std::map<MeasureId,MeasureStats> runMonteCarlo(const Model&, int totalRuns, uint64_t seed, int threads) = 0;
  // GeoFactor 灵敏度矩阵（README §7.4）—— High-Low 差商
  virtual Matrix runGeoFactor(const Model&) = 0;
  // Contributor HLM（README §7.5）—— GF²σ² 贡献比
  virtual ContributorTable runContributor(const Model&) = 0;
};
```

### 3.6 插件接口（A8 实现 Host，对齐 README §13 的 C ABI）
```c
/* interfaces/dcs_plugin_api.h —— C ABI，复刻 README §13.2 */

```

## 4. 协同机制与工作流

### 4.1 仓库与分支
- **单仓 monorepo**，目录按模块隔离：`/engine/{geometry,move,tolerance,measure,sim}`、`/domain`、`/app`、`/ui`、`/interfaces`、`/plugins`、`/tests`。
- 每个智能体在自己的 worktree/分支开发（`feat/A1-geometry` 等），只改自己模块目录 + 经 RFC 改 `/interfaces`。
- 合并到 `develop` 须过 CI 门禁（§7）；`main` 为里程碑稳定版。

### 4.2 契约优先（Contract-First）
1. A0 先交付 `/interfaces/*.h` + 每个接口的 **Mock 实现** + **契约测试**（接口语义的可执行规约）。
2. 各智能体先对 Mock 编程，模块内部并行推进，不等彼此实体完成。
3. 实体替换 Mock 时，契约测试保证行为一致。

### 4.3 跨模块沟通
- **接口变更** → 在 `/interfaces/RFC/` 提 RFC（动机+变更+影响模块+迁移），A0 + 受影响智能体评审。
- **数据格式**（WTX schema、统计量 JSON）由 A2/A6 拥有，同样版本化。
- **每日同步点**：各智能体把当日「接口消费/产出变化、阻塞、需要的上游」写进 `STATUS.md`（A0 汇总）。

### 4.4 集成节奏
- 每阶段末做一次**端到端集成验证**：用 A0 维护的「黄金模型」（一个标准装配，README §17 教程模型可作蓝本）跑通该阶段应支持的全链路。

## 5. 开发里程碑（5 个阶段）

对齐 README §0.5 复刻路线图。

### 阶段 0 · 地基（2-3 周）—— A0 主导，全员参与评审
- A0：monorepo 骨架、CMake/Conan、CI（编译+静态分析+单测+覆盖率）、代码规范、ADR。
- A0：冻结 `/interfaces/` v1.0 全部接口 + Mock + 契约测试。
- 全员：评审接口，确认各自模块能基于它独立开发。
- **门禁**：CI 绿、Mock 跑通一个「空装配」端到端冒烟。

### 阶段 1 · 几何与数据底座（4-6 周）
- **A1**：几何实体创建、Mesh 双层模型、LSQ 拟合、方向系统。
- **A2**：AssemblyTree 有序树、全部领域对象、WTX 序列化、Logic Tree 语义（节点顺序=Move 顺序）。
- **A8**（启动）：Qt 主窗 + Model Navigator 树（读 A2 模型）+ Graphic Window 壳（嵌 A1 viewer）。
- **门禁**：能新建/打开模型、在树上建点/特征、3D 显示、存读 WTX 往返一致。

### 阶段 2 · 公差链核心引擎（8-10 周）—— **关键阶段，最小可用仿真**
- **A3**：21 种 Move（先 Six-Plane/Three-Point/Two-Point/Step-Plane 通用 6 种，再扩全）。
- **A4**：公差抽样器、16+4 分布、RSS、GD&T→几何映射（先 Size/Position/Profile，再扩 19 种）。
- **A5**：全部 Measure（先 Point Distance/Feature/Combination，再扩 GD&T Measure/Equation）。
- **A6**：Monte Carlo 主循环 + 全部统计量 + 收敛 + Headless CLI（对齐 Batch Processor）。
- **门禁**：**黄金模型跑通完整 Monte Carlo 闭环**，统计量与手册算例/参考实现一致，同 seed 可复现。

### 阶段 3 · 分析与可视化（6-8 周）
- **A6**：GeoFactor 灵敏度矩阵 + Contributor HLM + 贡献百分比。
- **A7**：装配状态机、Deviate/Sweep、Color Contour 着色、Animation、HTML/Excel 报告。
- **A8**：Simulation Window（直方图/统计表/贡献度表）、MTM 编辑对话框全套、Preferences。
- **门禁**：从建模到出报告全链路；GeoFactor 与 Monte Carlo 6σ 在线性模型上吻合（README §7.4 线性度校验）。

### 阶段 4 · 加固与扩展接口（4-6 周）
- 全员：性能优化（多线程仿真、网格缓存）、大装配压测、稳定性。
- **A8**：插件 Host（C ABI）+ 加载 UI；预留 AAO/FEA/Mechanical 的模块插槽（接口占位，不实现）。
- **A2/A7**：CAD 适配层接口（README §12 通用机制），先做 STEP/IGES 导入（OCCT 原生）。
- **门禁**：通过验收测试集；插件 demo 跑通；文档齐全。

> 总工期估算：核心全功能版约 **24-33 周**（6-8 个月），8-9 个并行智能体。

## 7. 测试与质量门禁

| 层级 | 测试类型 | 拥有者 | 门禁 |
|---|---|---|---|
| 接口 | 契约测试(语义规约) | A0 | 实体必过 Mock 同款契约测试 |
| 单元 | 各模块单测(算法正确性) | 各 A | 覆盖率 ≥70%，核心算法 ≥85% |
| 数值 | 统计量/灵敏度对标参考值 | A6 | Monte Carlo 同 seed 完全可复现；GeoFactor↔MC 线性吻合 |
| 集成 | 黄金模型端到端 | A0 | 每阶段末全链路绿 |
| 性能 | 大装配压测 | A6/A1 | 万次仿真 + 千零件不崩、内存可控 |
| 回归 | 黄金模型快照 | A0 | 统计量数值回归不漂移 |

**关键数值断言**（README 已给基准）：
- 收敛：3%@95% → 2137 轮，1%@99% → 33178 轮。
- GeoFactor 与 Monte Carlo 在线性模型上 6σ 吻合（线性度校验）。
- σ 用 /n（总体方差）；贡献百分比按 GF²σ² 平方比例分配。
- 同 seed + 同轮数 + 同遍历顺序 → 逐位可复现。

## 8. 风险与依赖管理

| 风险 | 影响 | 缓解 |
|---|---|---|
| 接口频繁变更致下游返工 | 高 | 契约优先 + 阶段 1 末冻结 v1.0 + RFC 流程 |

## 9. 智能体协作守则

1. **接口即法律**：只对 `/interfaces/` 编程，不跨模块 include 实现；接口变更走 RFC。
2. **契约优先**：先有 Mock + 契约测试，再填实体；下游不等上游实体，对 Mock 并行开发。
3. **单一所有权**：每个模块目录只有一个智能体写；他人需要的能力经接口暴露。
4. **可复现红线**：任何触碰随机数/遍历顺序的改动必须保持 seed 可复现，违者 CI 拦截。
5. **Headless 可测**：L1 内核任何功能须能脱离 UI 在 CLI/单测中验证。
6. **每日 STATUS**：写清接口产出/消费变化、阻塞、需要的上游，A0 汇总。
7. **阶段门禁不通过不进下一阶段**：黄金模型端到端必须绿。
8. **数值对标**：算法实现以 README 给出的公式/基准为准绳，偏差需在测试中显式标注。
