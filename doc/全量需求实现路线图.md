# OpenDVA 全量需求实现路线图

目标：把 `doc/需求文档.md` 描述的 3DCS Variation Analyst 风格软件，从当前 headless/reference + Desktop MVP 起点，推进到工业化、可交付、可验收的完整软件。

创建时间：2026-06-10

## 0. 总原则

1. `doc/需求文档.md` 是产品需求主源。
2. `doc/交付差距审计.md` 是当前缺口主源。
3. `src/` 当前实现是工程基线，已有能力保留并扩展，不重写一套平行系统。
4. 每个阶段必须产生可运行软件，不接受只写接口或只写文档。
5. 每个模块必须有验收命令或可操作验收流程。
6. 高级模块可以分 license/feature flag 暂时隐藏，但“全量实现”最终必须覆盖需求第 0-14 章。

## 2. 交付阶段

### 阶段 A：桌面建模闭环

目标：用户可以在 UI 中完成基础建模、保存、打开、运行、报告。

必须完成：

- Model Navigator 右键菜单：Add Part、Add Point、Add Feature、Add Tolerance、Add Move、Add Measure。
- 属性面板可编辑基础对象。
- Move 列表拖放重排。
- Validation Window：显示缺失点、空公差、无测量、未引用 Feature 等问题。
- Preferences：单位、默认 runs/seed/thread、报告路径。
- 最近文件、脏状态、错误提示。

验收：

1. 新建模型。
2. 添加 2 个点、1 个 Linear Tolerance、1 个 Point-Point Measure。
3. 保存、关闭、重新打开。
4. 运行 Monte Carlo。
5. 导出 HTML/CSV/Excel XML。
6. Qt3D 视图显示点和测量线。

### 阶段 B：核心 MTM 全覆盖

目标：第 4-6 章核心 Move/Tolerance/Measure 在 headless 与 UI 中都可用。

必须完成：

- 21 种 Move solver 与参数 UI。
- 19 种 GD&T 与 3DCS Tolerance UI。
- 全 Measure 精确实现，移除当前参考近似和缺失上下文行为。
- User-DLL Move/Tolerance/Measure 可被模型引用。
- MTM Copy/Delete/Convert/Reorder。

验收：

- 每种 Move 至少 1 个单测 + 1 个 UI 建模 smoke。
- 每类 GD&T 至少 1 个抽样/测量测试。
- 当前 `rg "TODO|not implemented|stub"` 不再命中核心 MTM 未实现项。

### 阶段 C：仿真分析工业化

目标：第 7 章完整可用。

必须完成：

- Run Analysis 设置窗口。
- Monte Carlo、GeoFactor、Contributor 三分析同窗口显示。
- 直方图、样本表、贡献度表、HST/HLM 后端保存/加载、UI 保存入口与加载入口。
- Batch Processor 队列监控/暂停重试 + 更高级的每作业分析配置。
- 线程设置和可复现随机数验证。

验收：

- 同 seed + runs 可复现。
- GeoFactor 与 Monte Carlo 在线性模型中吻合。
- HST/HLM 文件可保存、重新加载，并可由 workflow 与报告流消费。

### 阶段 D：Qt3D 可视化与报告

目标：第 8 章完整可用。

必须完成：

- Nominal Build、Assemble、Separate、Deviate、Sweep。
- Color Contour 云图、Legend、Lines。
- Animation 控制。
- Report Generation：已有 UI HTML 当前 Qt3D 视图截图嵌入和 Samples/Contributor 明细；继续补截图质量控制、模板化表格和统计图。
- Spec Study、Gap & Flush 基础。

验收：

- Qt3D 视图可以显示装配状态变化。
- 云图颜色和统计结果绑定。
- 报告包含模型视图、统计表、图表和测量结果。

### 阶段 E：几何内核与 Multi-CAD 基础

目标：第 3/12/14 章几何能力工业化。

必须完成：

- OCCT-backed `IGeometryKernel`。
- STEP/IGES 导入。
- 点/线/圆/平面/球/槽/孔特征创建与编辑。
- Mesh Control、Feature/Coordinate/Dynamic Point。
- PMI/约束适配接口。

验收：

- `OPENDVA_USE_OCCT=ON` 构建通过。
- STEP 示例模型导入后可建点、建特征、建测量、运行仿真。

### 阶段 F：AAO 高级分析

目标：第 9 章完整可用。

必须完成：

- SBS、GeoFactor Matrix、CTI、TO、SO、DO、LSA。
- 优化目标、约束、成本函数、矩阵保存/加载。
- AAO 结果窗口和报告。

验收：

- 每个 AAO 工具有标准模型和数值回归。
- TO 能自动调整公差并改善目标指标。
- SO/DO 能输出排序和候选方案。

### 阶段 G：Mechanical 机构模块

目标：第 10 章完整可用。

必须完成：

- Constraints 和 9 种 Joints。
- DOF Counter。
- Kinematics。
- Gear Module。
- Collision Detection / Part Distance。

验收：

- 标准机构模型可以做运动学仿真。
- DOF 计数与约束组合一致。
- 碰撞/距离测量输出稳定。

### 阶段 H：FEA Compliant 柔性模块

目标：第 11 章完整可用。

必须完成：

- FEA 数据加载、ASET 链接、刚度/质量/热载荷矩阵。
- Clamp、UnClamp、Join、Multiple Parts Join、LockDOF、UnLockDOF。
- Force、Contact、UnContact、Thermal、Gravity、Torque、Force Measure。
- 柔性模型验证器。

验收：

- 线弹性矩阵求解 `{d}=[K]^-1{F}` 正确。
- Clamp/Join/UnClamp 有回弹结果。
- 缺文件、欠约束、矩阵不可逆能被验证器发现。

### 阶段 I：CAD/插件/部署

目标：第 12/13 章工程化交付。

必须完成：

- User DLL SDK、示例、加载 UI。
- CAD Adapter 接口和 Multi-CAD 独立流程。
- 安装包、依赖检查、系统信息、日志、崩溃诊断。
- 帮助入口和教程模型。

验收：

- 示例插件能注册 Move/Tolerance/Measure 并被 UI 调用。
- 安装后能启动 GUI、打开示例、运行报告。

## 3. 当前优先级

当前代码已经完成阶段 A 的第一小步：Qt3D UI 壳、文件流、结果窗口、报告导出、HST/HLM 后端读写与 workflow/CLI/Simulation Window 保存/加载、workflow 批处理队列后端及每作业 runs/seed/threads 覆盖、失败项 retry job 重建、CLI batch manifest 每作业参数、UI Batch Processor 表格化每作业 runs/seed/threads、CLI 批处理列表多格式导出 MVP，以及 UI HTML 当前 Qt3D 视图截图和 Samples/Contributor 明细嵌入。

下一步优先做阶段 A 剩余项：

1. Model Navigator 右键菜单与基础对象创建。
2. 属性面板可编辑点、公差、测量。
3. Qt3D 显示测量线与特征简化几何。
4. Validation Window。
5. Preferences。

理由：没有完整建模入口，后续 B-I 的能力即使写好也无法被工业用户稳定使用。

## 4. 完成判定

只有当以下证据全部成立，才能宣称 `doc/需求文档.md` 全量实现完成：

1. 需求章节 0-14 的每个功能都有代码入口、UI 入口或明确的 CLI/API 入口。
2. 每个入口有测试、示例模型或手动验收步骤。
3. `rg "TODO|not implemented|placeholder|scaffold|stub"` 不再命中未交付功能。
4. `OPENDVA_BUILD_UI=ON`、`OPENDVA_USE_OCCT=ON`、测试和示例模型全部通过。
5. GUI 可完成建模、仿真、分析、可视化、报告、插件加载。
6. AAO、Mechanical、FEA、CAD/插件这些原计划暂不含模块已全部补齐或通过 license/feature flag 作为交付功能启用。
